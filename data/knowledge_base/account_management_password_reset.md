# Password Reset

A password reset request should start with identity verification so the account remains secure. After verification, support can send a reset link or guide the customer through the self-service password reset flow. Customers should be reminded to use a unique password that they are not reusing on other accounts.

If the customer cannot access the email or phone number on file, the account may require an alternate verification path. Agents should avoid sharing any password details and should only confirm whether the reset link was sent successfully. Once the password is changed, the customer should be encouraged to update any stored login information on their devices.
