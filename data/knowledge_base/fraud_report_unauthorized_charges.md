# Unauthorized Charges

If a customer reports unauthorized charges, support should treat the issue as time-sensitive and review recent billing activity right away. The agent should confirm which charges are being questioned, whether the customer recognizes the payment method used, and whether there have been any unusual changes to the account. Fraud cases often involve duplicate charges, unexpected device purchases, or small test transactions before a larger attempt.

Customers should be advised to monitor their payment accounts and change passwords if any account access seems suspicious. If the evidence suggests actual fraud, the case should be escalated according to the account security process so the charges can be reviewed and the account protected. Clear documentation of the disputed transaction helps investigators act faster.
