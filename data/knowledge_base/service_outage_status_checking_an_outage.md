# Checking Outage Status

When a customer asks about an outage, verify their service address and ask whether the problem is total loss of service or a partial degradation such as slow speeds or dropped calls. The outage status should be checked against the local network map before starting device-level troubleshooting. If there is a known outage, the customer should be informed that restoration timelines can change as field crews evaluate the affected area.

If there is no active outage in the area, support should continue with targeted troubleshooting for the customer's specific line or device. This distinction is important because a local outage, a neighborhood impairment, and a home equipment problem can produce similar symptoms. Clear communication helps set expectations and avoids unnecessary repeat troubleshooting while the wider issue is being repaired.
