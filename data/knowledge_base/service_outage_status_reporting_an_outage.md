# Reporting a Service Outage

Customers should report a service outage when multiple devices lose connectivity at the same time, the modem shows normal power but no network signal, or voice service drops across the entire home. When collecting the report, confirm the service address, the time the issue started, and whether neighboring homes or nearby businesses are affected as well. Those details help operations distinguish between a single-account problem and a broader network event.

Once the outage is logged, the customer should be told what to expect next. If a known issue already exists, the report may simply attach their account to the active event; if no issue is known, the report can help create a new investigation. Support should avoid promising an exact restore time unless one has been provided by network operations.
