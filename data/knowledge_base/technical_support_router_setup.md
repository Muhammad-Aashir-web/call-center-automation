# Router Setup Basics

For a new router install, the customer should connect the modem to the router's WAN or Internet port, then wait for the status lights to stabilize before testing a device connection. If the router supports a setup app or web portal, use the default login process first and change the Wi-Fi name and password after the connection is confirmed. Customers often skip the modem reboot step, but that step is important when the router is newly connected.

If the customer is replacing an older router, advise them to disconnect the old unit completely before powering up the new one. That prevents the modem from holding onto the old device's MAC address or stale connection state. Once the router is online, verify that both the 2.4 GHz and 5 GHz networks are broadcasting and that the customer can connect on at least one of them.
