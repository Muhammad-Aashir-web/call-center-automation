# Troubleshooting Slow Internet

When a customer reports slow internet, start with the basics: reboot the modem and router, check whether the slowdown affects one device or every device, and confirm whether the issue is happening on Wi-Fi or wired Ethernet. If only Wi-Fi is slow, the cause is often signal interference, distance from the router, or congestion on the 2.4 GHz band.

Support should also ask whether speed problems happen at certain times of day or only during streaming, gaming, or video calls. Those details help separate a local home-network issue from a broader line-quality problem. If possible, have the customer run a speed test next to the router and then again in a different room so the agent can compare the results and narrow down the likely cause.
